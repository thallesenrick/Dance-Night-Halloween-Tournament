# Retro cursor sprites

Original pixel SVG assets created for this application, inspired by classic1990s desktop cursor shapes. Fixed32×32 viewports and explicit CSS hotspots retain native hit testing; no JavaScript cursor follower is used.

References researched:
- Windows95-era UI: https://www.webdesignmuseum.org/software/internet-explorer-2-0-in-1995
- Classic beveled controls: https://jdan.github.io/98.css/
- CSS cursor images/hotspots: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/cursor

States: arrow, clickable hand, open/closed drag hand, text insertion, placement crosshair, disabled and wait.
